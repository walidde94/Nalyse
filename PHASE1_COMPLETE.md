### ✅ Authentication

### ✅ Security

- Input validation with express-validator

- Helmet.js security headers

### ✅ Multi-Tenancy
- Organization model with plans (free/pro/enterprise)
- Storage quotas per organization
- User limits per plan
- File ownership tracking

## 📡 **API Endpoints**

### Public (No Auth Required)
- `POST /api/auth/register` - Create account
- `POST /api/auth/login` - Get tokens
- `POST /api/auth/refresh` - Refresh access token
- `POST /api/auth/request-password-reset` - Request reset
- `POST /api/auth/reset-password` - Reset with token
- `GET /api/auth/verify-email/:token` - Verify email

### Protected (Requires JWT)
- `GET /api/auth/profile` - Get current user
- `POST /api/auth/logout` - Logout (log event)

  -H "Content-Type: application/json" \

    "password": "TestPass123",
    "firstName": "Test",
    "lastName": "User"

# Login

  -H "Content-Type: application/json" \
  -d '{

    "password": "TestPass123"
  }'

## 💡 **Key Decisions Made**

1. **TypeORM over Prisma** - Better TypeScript integration, more mature
2. **JWT over Sessions** - Scalable, stateless, works with mobile apps
3. **Organization-first model** - Every user belongs to an organization (B2B SaaS)
4. **Auto-create organization** - Seamless onboarding experience
5. **Refresh tokens** - Better UX (don't force re-login every 15 min)
