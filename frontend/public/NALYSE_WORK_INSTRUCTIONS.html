01. Workspace & Lifecycle Management

The Workspace is the primary command center for organizational intelligence. Every asset ingested here fuels the downstream AI and predictive models.

1.1 Procedure: Strategic File Ingestion

Code Action Item Technical Validation
1.1.1 Initiate Upload Navigate to Dashboard. Trigger Upload Data modal.
1.1.2 Format Verification File must be UTF-8 encoded .CSV, .JSON, or .XLSX. Max size 500MB/file.
1.1.3 Lifecycle Pinning Use the Star icon to protect mission-critical datasets from auto-archiving.
Neural Context The "Enterprise Pulse" logic automatically calculates Revenue Velocity by identifying numeric columns with monetary headers. If no monetary headers are found, the engine defaults to row-count volume analysis.

03. Strategic Board Operations

The Strategic Board translates AI findings into human-executable projects. This is the bridge from 'Data' to 'Done'.

3.1 Procedure: Project Lifecycle Escalation

  • Creation: Manually create or promote from a Nexus AI Finding.
  • Status Logic: Proposed ➔ In Progress ➔ Review ➔ Executed.
  • Asset Linking: Attach specific Workspace files to the project card for auditor visibility.

Nexus AI (The Oracle) performs high-order reasoning across multi-departmental silos.

4.1 Procedure: The Strategic Synthesis Loop

Stage System Interaction Output Expectation

07. Visual BI & Analytics Builder

Converting raw metrics into board-ready executive visualizations.

7.1 Procedure: Drag-and-Drop Chart Construction

Component Interaction Result
Dimension Drag 'Date' or 'Category' to the Drop Zone. Defines the chart's X-Axis hierarchy.
Measure Drag 'Revenue' or 'Count' to the Measure Zone. Defines the Y-Axis data points.
Chart Type Toggle Bar/Line/Donut in the Visual Settings sidebar. Updates visualization type instantly.

09. Data Migration & Normalization

Standardizing legacy "Dirty Data" for reliable organizational reporting.

9.1 Procedure: Schema Alignment Protocol

  • Select 'Legacy_Export_2023.csv' in the Migration view.
  • Map Total_AMT to the system-standard Revenue.
  • Run Full Transformation Macro.
  • Verify new file generation on the Dashboard with [NORMALIZED] prefix.
